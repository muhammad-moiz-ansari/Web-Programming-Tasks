# Comprehensive Prompt: Cat Art Gallery Website Clone

## **Project Overview**
Create a single-page, responsive website for "Cat Alley Collection" (also referred to as Catalley/Catally), a feline art gallery. The website should capture the whimsical, artistic spirit of cats while maintaining professional web design standards. All code must be in ONE HTML file with embedded CSS.

## **Core Requirements**

### **1. HTML5 Semantic Structure (2 marks)**
- Use proper semantic elements: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Implement semantic tags for content organization
- Ensure logical document outline without using generic `<div>` where semantic tags apply

### **2. CSS Selectors (2 marks)**
- **Type Selectors:** Style HTML elements directly (h1, p, a, etc.)
- **Class Selectors:** Use `.class-name` for reusable styles
- **ID Selectors:** Use `#id-name` for unique elements
- Demonstrate hierarchy: `nav ul li a`

### **3. Navigation Bar with Pseudo-classes (2 marks)**
- Create a fixed/sticky navigation bar with: Home, About, Gallery, Feedback, Sign In, Sign Up
- Implement pseudo-classes for all navigation links:
  - `:hover` - change color/background on mouseover
  - `:active` - style when being clicked
  - `:focus` - style for keyboard navigation accessibility
- Consider `:before` or `:after` for decorative elements

### **4. External CSS Simulation (2 marks)**
- Include all CSS within `<style>` tags in the HTML file
- Organize CSS logically: reset, variables, typography, layout, components, responsive
- Use CSS comments to separate sections

### **5. Visual Design (2 marks)**
- **Background:** Gradient or subtle cat-pattern background image
- **Color Scheme:** 
  - Primary: Warm tones (oranges, creams for ginger cats)
  - Accent: Blues/greys for contrast
  - Text: Dark grey/black with white for contrast
- **Fonts:** Use Google Fonts (suggestions: 'Poppins' for headings, 'Open Sans' for body)
- Implement a cohesive color palette using CSS variables

### **6. Creativity & Originality (2 marks)**
- Add subtle cat-themed animations (paw prints, tail wags)
- Create custom cat-shaped elements or borders
- Implement a "cat of the day" feature
- Add interactive hover effects on gallery images
- Include Easter eggs or playful elements consistent with cat theme

### **7. Responsive Design with Media Queries (2 marks)**
- Mobile-first approach
- Breakpoints:
  - Mobile: < 768px
  - Tablet: 768px - 1024px
  - Desktop: > 1024px
- Responsive gallery grid (flexbox or CSS grid)
- Collapsible navigation menu for mobile
- Adjust font sizes, padding, and margins for each viewport

### **8. Typography with Web Fonts (2 marks)**
- Import at least 2 Google Fonts
- Establish typographic hierarchy:
  - h1: 2.5rem-3rem
  - h2: 2rem-2.5rem
  - h3: 1.5rem-1.75rem
  - Body: 1rem-1.2rem
- Set proper line-height (1.5-1.6 for body)
- Implement responsive font sizes using `rem` units

### **9. CSS Icons (2 marks)**
- **Font Awesome:** Use for social media, user account, and navigation icons
- **Google Icons/Material Icons:** Use for buttons, forms, and decorative elements
- Implement icon-only buttons for mobile
- Ensure icons are accessible with proper ARIA labels

### **10. Overall Neatness & Professionalism (2 marks)**
- Clean, well-commented code
- Consistent indentation and formatting
- No broken links or placeholder text in final version
- Proper use of whitespace
- Accessible color contrast ratios
- Valid HTML5 and CSS3
