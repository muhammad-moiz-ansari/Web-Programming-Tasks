Create a React application that implements client-side routing using React Router with three main pages: Home, About, and Contact. The Home component should display a simple welcome message, while the About component should provide brief information about the application. The Contact component must include a controlled form with input fields for name, email, and message. Each form field should be connected to the component’s state using useState, ensuring that the input values are controlled and updated through onChange handlers. When the user submits the form, prevent the default form behavior, log the entered data to the console, and optionally clear the form fields. Additionally, include a navigation bar that allows users to switch between the Home, About, and Contact pages without reloading the page.
